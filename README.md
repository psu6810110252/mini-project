**6810110474 นภัทรทสร ณ พัทลุง**


ชื่อโปรเจ็ค: เว็บซื้อขายเลคเชอร์ออนไลน์

โปรเจ็คนี้เป็นการพัฒนาเว็บไซต์สำหรับ ซื้อ–ขายเลคเชอร์ออนไลน์ โดยมีเป้าหมายเพื่อเป็นแพลตฟอร์มที่ช่วยให้นักเรียนหรือนักศึกษาสามารถเข้าถึงเลคเชอร์คุณภาพได้ง่ายขึ้น และเปิดโอกาสให้ผู้ที่มีความรู้สามารถนำเลคเชอร์ของตนเองมาจำหน่ายได้อย่างสะดวก
เว็บไซต์รองรับการทำงานหลัก เช่น
- การแสดงรายการเลคเชอร์ที่มีจำหน่าย
- การดูรายละเอียดเลคเชอร์ เช่น ชื่อวิชา ราคา และคำอธิบาย
- ระบบซื้อเลคเชอร์ผ่านเว็บไซต์
- การจัดการเลคเชอร์ของผู้ขาย (เพิ่ม/แก้ไข/ลบข้อมูลเลคเชอร์)

 โปรเจ็คนี้มุ่งเน้นการออกแบบระบบให้ใช้งานง่าย (User-friendly) และจำลองการทำงานของเว็บ E-commerce ในบริบทของการศึกษา โดยเป็น Mini Project ที่ช่วยฝึกทักษะด้านการพัฒนาเว็บและการออกแบบระบบเบื้องต้น
