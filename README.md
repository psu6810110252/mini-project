โปรเจกต์ **Lecture Web** คือเว็บแอปพลิเคชันขายสรุปเนื้อหาออนไลน์ที่ทำขึ้นเพื่อการเรียนรู้ ซึ่งมีระบบการจัดการสินค้าและสั่งซื้อสินค้า โดยเราแยกการทำงานออกเป็น 2 ฝั่งชัดเจน คือ **หน้าบ้าน (Frontend)** และ **หลังบ้าน (Backend)**

## 🛍️ การทำงานของเว็บไซต์
เว็บไซต์นี้จำลองระบบซื้อขาย lecture online โดยเริ่มจาก:
1.  **ดูสินค้า:** ใครๆ ก็เข้ามาดูรายการสินค้าหน้าร้านได้
2.  **สมัครสมาชิก/ล็อกอิน:** ถ้าจะซื้อ lecture ต้องลงทะเบียนเป็นสมาชิกก่อน(ระบบจะได้รู้ว่าใครส่ง lecture ไปที่ไหน)
3.  **สั่งซื้อ (Order):** เลือก lecture ใส่ตะกร้า แล้วกดสั่งซื้อ ระบบจะบันทึกออเดอร์นั้นไว้ทันที
4.  **ดูประวัติ:** ลูกค้าสามารถกลับมาดูย้อนหลังได้ว่าเคยสั่งอะไรไปบ้าง

---

## 1. 🖥️ Frontend:  (React)
> *Location: `/frontend`*

ส่วนนี้คือ **"หน้าตาของเว็บไซต์"** ที่สามารถคลิกได้ ใช้ **React** สร้างขึ้นมา

*   **React Source Code:** เขียนโค้ดเพื่อสร้าง "ชิ้นส่วน" (Components) ต่างๆ เช่น ปุ่มกด, การ์ดสินค้า, แถบเมนู แล้วเอามาประกอบกันเป็นหน้าเว็บ
*   หน้าที่หลักคือ **คอยรับแขก** เวลามีลูกค้ามากดสั่งของ หรือจะดูสินค้า Frontend จะรับเรื่องแล้วส่งต่อไปถามข้อมูลจาก Backend ให้เห็นทันที ไม่ต้องรอนาน

## 2. ⚙️ Backend: (NestJS + Docker)
> *Location: `/backend`*

*   **NestJS Source Code:** นี่คือตัวหลักของโค้ด ที่ทำหน้าที่เป็นผู้จัดการร้าน
    *   คอยตรวจสอบว่า "คนนี้ล็อกอินถูกไหม?", "สต็อกของเหลือเท่าไหร่?", "คำนวณราคาสินค้าถูกต้องหรือเปล่า?"
    *   ถ้าทุกอย่างจำถูกต้อง จะอนุญาตให้ผ่านไปได้ (Authentication & Logic)
*   **docker-compose.yml:** 
    *   ปกติถ้าจะใช้ฐานข้อมูล (Database) 
    *   แต่ไฟล์นี้จะสั่งให้คอมพิวเตอร์ **"สร้างกล่องจำลองฐานข้อมูล"** (Container) ที่มีฐานข้อมูล **PostgreSQL** เตรียมไว้ให้พร้อมใช้งาน
